Setup Guide

Полная инструкция по установке и запуску Lecture Voice-to-Notes Local AI Study Workspace на Windows и macOS.

Содержание

1. Git 2. Python 3. Ollama и модели 4. ffmpeg 5. Скачать проект 6. Виртуальное окружение 7. Зависимости 8. Запуск 9. Повторный запуск Проблемы

Что нужно установить

Ссылка на проект: https://github.com/meosn/lecture-voice-to-notes/tree/local-ai-study-workspace

Git
Python 3.10+
Ollama
ffmpeg

Открывайте команды в Windows PowerShell. После установки Python, Git, Ollama или ffmpeg лучше закрыть PowerShell и открыть заново.

1. Установить Git

Скачать Git для Windows:

https://git-scm.com/download/win

После установки открыть PowerShell и проверить:

PowerShell
git --version

2. Установить Python

Скачать Python для Windows:

https://www.python.org/downloads/windows/

Во время установки обязательно поставить галочку Add python.exe to PATH.

Проверить:

PowerShell
python --version

Если команда выше не работает, попробовать:

PowerShell
py --version

3. Установить Ollama и модели

Скачать Ollama:

https://ollama.com/download

После установки проверить:

PowerShell
ollama --version

Скачать локальные модели:

PowerShell
ollama pull llama3.1:8b
ollama pull qwen2.5vl:7b

Проверить, что модели скачались:

PowerShell
ollama list

В списке должны быть llama3.1:8b и qwen2.5vl:7b.

4. Установить ffmpeg

Самый простой способ через winget:

PowerShell
winget install Gyan.FFmpeg

Закрыть PowerShell, открыть заново и проверить:

PowerShell
ffmpeg -version

Если winget не работает, скачать вручную:

https://ffmpeg.org/download.html

5. Скачать проект

Перейти на Desktop:

PowerShell
cd Desktop

Скачать репозиторий:

PowerShell
git clone https://github.com/meosn/lecture-voice-to-notes.git

Перейти в папку проекта:

PowerShell
cd lecture-voice-to-notes

Переключиться на нужную ветку:

PowerShell
git checkout local-ai-study-workspace

6. Создать виртуальное окружение

PowerShell
py -m venv .venv

Активировать окружение:

PowerShell
.\.venv\Scripts\Activate.ps1

Если PowerShell запрещает запуск скриптов:

PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Потом снова активировать:

PowerShell
.\.venv\Scripts\Activate.ps1

Если всё получилось, слева в командной строке появится (.venv).

7. Установить зависимости

PowerShell
python -m pip install --upgrade pip
pip install -r requirements.txt

Установка может занять несколько минут.

8. Запустить приложение

PowerShell
streamlit run app.py --server.port 8501 --server.address localhost

Открыть в браузере:

http://localhost:8501

9. Как запускать потом

Каждый раз заново устанавливать всё не нужно. Достаточно:

PowerShell
cd Desktop\lecture-voice-to-notes
.\.venv\Scripts\Activate.ps1
streamlit run app.py --server.port 8501 --server.address localhost

Остановить приложение:

Keyboard
Ctrl + C

Если что-то пошло не так

Порт 8501 занят

PowerShell
streamlit run app.py --server.port 8502 --server.address localhost

Открыть:

http://localhost:8502

Ollama не работает

PowerShell
ollama list

Если моделей нет, снова выполнить:

PowerShell
ollama pull llama3.1:8b
ollama pull qwen2.5vl:7b

Аудио не обрабатывается

Проверить ffmpeg:

PowerShell
ffmpeg -version

Открывайте команды в приложении Terminal. Его можно найти через Spotlight: нажать Cmd + Space и написать Terminal.

1. Установить инструменты

Сначала установить Apple Command Line Tools. Они нужны для Git и сборки некоторых Python-зависимостей:

Terminal
xcode-select --install

Проверить Git:

Terminal
git --version

Проверить Python:

Terminal
python3 --version

Если Python старый или не найден, установить свежий Python с официального сайта:

https://www.python.org/downloads/macos/

2. Установить Ollama и модели

Скачать Ollama для macOS:

https://ollama.com/download

После установки открыть Ollama один раз из Applications, затем проверить в Terminal:

Terminal
ollama --version

Скачать локальные модели:

Terminal
ollama pull llama3.1:8b
ollama pull qwen2.5vl:7b

Проверить, что модели скачались:

Terminal
ollama list

В списке должны быть llama3.1:8b и qwen2.5vl:7b.

3. Установить ffmpeg

Если Homebrew уже установлен, выполнить:

Terminal
brew install ffmpeg

Если Homebrew не установлен, сначала поставить его:

Terminal
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

После установки Homebrew закрыть Terminal, открыть заново и выполнить:

Terminal
brew install ffmpeg
ffmpeg -version

4. Скачать проект

Перейти на Desktop:

Terminal
cd ~/Desktop

Скачать репозиторий:

Terminal
git clone https://github.com/meosn/lecture-voice-to-notes.git

Перейти в папку проекта и выбрать нужную ветку:

Terminal
cd lecture-voice-to-notes
git checkout local-ai-study-workspace

5. Создать виртуальное окружение

Terminal
python3 -m venv .venv

Активировать окружение:

Terminal
source .venv/bin/activate

Если всё получилось, слева в командной строке появится (.venv).

6. Установить зависимости

Terminal
python -m pip install --upgrade pip
pip install -r requirements.txt

Установка может занять несколько минут.

7. Запустить приложение

Terminal
streamlit run app.py --server.port 8501 --server.address localhost

Открыть в браузере:

http://localhost:8501

Terminal

source .venv/bin/activate
streamlit run app.py --server.port 8501 --server.address localhost
